# 胡羽真｜日系簡約個人網站

這是一個單頁式個人網站，使用原生 HTML、CSS、JavaScript，不需要安裝任何套件。

## GitHub Pages 上傳方式

1. 將 ZIP 解壓縮。
2. 登入 GitHub，建立一個 Public repository，例如 `yu-chen-portfolio`。
3. 在儲存庫首頁選擇 **Add file → Upload files**，將 `index.html`（以及本說明檔）上傳到儲存庫根目錄。
4. 到 **Settings → Pages**，將 Source 設為 **Deploy from a branch**，選擇 `main`、`/(root)`，按 Save。
5. 等待部署完成，網站網址通常是 `https://你的帳號.github.io/yu-chen-portfolio/`。
